# MAHASART ต้นแบบเฟส 1–3

ต้นแบบที่กดได้จริงทั้งหน้าเว็บและหลังบ้าน ไม่ใช้เซิร์ฟเวอร์ ข้อมูลทั้งหมดเป็นตัวอย่าง · โดเมนจริง: https://mahasart.net

## เปิดใช้

- หน้าเว็บ: ดับเบิลคลิก `index.html`
- หลังบ้าน: ดับเบิลคลิก `admin/login.html` แล้วเลือกบทบาท (ไม่มีรหัสผ่าน)
- การแก้ไขในหลังบ้านเก็บใน localStorage ของเบราว์เซอร์ที่เปิดอยู่เท่านั้น · กด "คืนค่าข้อมูลตัวอย่าง" ที่เมนูซ้ายของหลังบ้านเพื่อเริ่มใหม่

## ลองวงจรหลัก

1. เข้าเป็น **กิตติ (ผู้เขียน)** → บทความ → "จัดโต๊ะทำงานตามฮวงจุ้ย" → ส่งตรวจ
2. เปลี่ยนเป็น **มาลี (บรรณาธิการ)** → เปิดบทความเดิม → เผยแพร่ → เห็นบนหน้า `articles.html`
3. บทความ "สีประจำวันทั้ง 7 วัน" (หมวดโหราศาสตร์ไทย) ต้องให้ **อาจารย์ธนา (โหร)** อนุมัติก่อน บรรณาธิการถึงเผยแพร่ได้
4. เข้าเป็น **สุดา (ผู้ดูแลแค็ตตาล็อก)** → วัตถุมงคล MH-0008 → เผยแพร่ไม่ได้จนกว่าจะเลือกป้ายประเภทและเพิ่มรูปพร้อมคำบรรยาย
5. **ปรีชา (ผู้ดูแลระบบ)** ดูบันทึกการใช้งาน ถังขยะ ผู้ใช้ และตั้งค่า (ลองเปิดโหมดปิดปรับปรุงแล้วเปิดหน้าเว็บในหน้าต่างส่วนตัว)
6. แดชบอร์ดมีตัวนับการเข้าชม (ออนไลน์ · วันนี้ · สัปดาห์นี้ · เดือนนี้ · ทั้งหมด) และแสดงที่ท้ายหน้าเว็บด้วย ปิดได้ที่ ตั้งค่า → ตัวนับการเข้าชม

## ลองเฟส 2–3 (สมาชิก ร้านค้า AI ผู้เชี่ยวชาญ คอร์ส)

สมาชิกตัวอย่าง (เข้าที่ปุ่ม "เข้าสู่ระบบ" มุมขวาบน ไม่มีรหัสผ่านจริง):

| สมาชิก | เข้าด้วย | แพ็กเกจ | ลองอะไรดี |
| --- | --- | --- | --- |
| นภา สุขใจ (napa@example.com) | LINE | พรีเมียม | ถาม AI ได้วันละ 30 ข้อ · เรียนคอร์สโหราศาสตร์ฟรี · จองนัดได้ส่วนลด 10% |
| ธนพล มีโชค (thanapon@example.com) | Google | ฟรี | ถาม AI วันละ 3 ข้อ · สมัครพรีเมียม 99 บาท |
| วิมล ศรีงาม (wimon@example.com) | อีเมล | ฟรี | มีคำสั่งซื้อรอชำระ · ซื้อคอร์ส |
| ปริญญา ใจดี | อีเมล | — | ถูกระงับ เข้าไม่ได้ |

1. ใส่วัตถุมงคลลงตะกร้า → กรอกที่อยู่ → หน้าชำระ PromptPay → กด "จำลองว่าโอนแล้ว" → หลังบ้าน **สุดา** แพ็กและใส่เลขพัสดุ → สมาชิกเห็นสถานะ
2. ดูดวงทักษา → "ให้ AI อธิบายผลนี้" · ลองพิมพ์คำถามเรื่องหวยหรือขอให้แนะนำพระ เพื่อดูว่า AI ปฏิเสธอย่างไร
3. จองอาจารย์ภูมิใจ → จ่าย → หลังบ้านเข้าเป็น **ภูมิใจ (ผู้เชี่ยวชาญ)** เห็นนัด เปิดห้องคุย และจบนัด → สมาชิกเขียนรีวิว
4. ซื้อคอร์สหรือสมัครพรีเมียม → เรียนจนจบ ทำแบบทดสอบ → ได้เกียรติบัตร
5. หลังบ้าน **ปรีชา (ผู้ดูแลระบบ)** ดูสมาชิก รายได้แยกช่องทาง และยอดที่ต้องโอนให้ผู้เชี่ยวชาญ

หน้าเว็บยืดเต็มความกว้างจอทุกขนาด (การ์ดเพิ่มคอลัมน์เองบนจอกว้าง) · หน้า Mahasart AI และห้องปรึกษาเป็นหน้าแชตแบบแอป: เต็มความสูงจอ กล่องพิมพ์ติดล่าง บนมือถือซ่อนหัวเว็บและเปิดรายการ/รายละเอียดเป็นลิ้นชัก

ทุกการจ่ายเงินในต้นแบบเป็นการจำลอง ระบบจริงจะยืนยันยอดจากธนาคารอัตโนมัติ · รายการที่ไม่จ่ายภายใน 30 นาทีจะยกเลิกเองและคืนสต็อก/คิว

## ตรวจงาน

```bash
node tools/check_prototype.js
```

`WIDTHS=1920,375` กำหนดขนาดจอเอง · `DARK=1` ตรวจธีมมืด

เปิดทุกหน้าด้วย Chrome แบบ headless ที่ 375/768/1280 px ตรวจ error, การเลื่อนแนวนอน, ลิงก์เสีย, ไอคอนที่หาย และ style/script แบบ inline · `SHOTS=1 FULL=1` เก็บภาพไว้ที่ `tools/shots/` · สูตรดวงทดสอบได้ที่ `tests.html`

## ช่วงทดสอบกับผู้ใช้

- ทุกหน้ามี `noindex,nofollow` (คอมเมนต์ "ลบ noindex ตอนเปิดระบบจริง" อยู่เหนือแท็ก) · ลบออกตอนเปิดจริง
- `guide.html` คือคู่มือผู้ทดสอบ (สมาชิกตัวอย่าง + ลองทำ 6 อย่าง · สถานะเก็บใน `mh_guide_done`) · ลิงก์อยู่ท้ายทุกหน้าและแถบบน `index.html`
- `feedback_url` ใน `data/system.js` (settings) ใส่ลิงก์ Google Form → มีปุ่มลอย "ส่งความเห็น" ทุกหน้า · ค่าว่าง = ไม่แสดง · ชุดคำถามอยู่ที่ `tools/FEEDBACK_FORM.md`
- แถบคุกกี้ใน `shell.js` เก็บผลที่ `mh_consent` = `{analytics, at}` · ถ้า `analytics:false` ไม่นับการเข้าชมในเบราว์เซอร์นี้ · เปิดใหม่ได้จาก "ตั้งค่าคุกกี้" ท้ายเว็บ
- มี `manifest.webmanifest` และไอคอนใน `assets/img/` (ต้นทาง `icon.svg`) · ภาพแชร์ `og-cover.png` สร้างจาก `tools/og-cover.html` · ไม่มี service worker

## สิ่งที่ยังเป็นค่าตัวอย่าง

- ตำรา: สีประจำวัน ช่วงราศี ค่าตัวอักษร และความหมายเลข รอโหรที่ปรึกษายืนยัน
- ตัวเลขการเข้าชมย้อนหลังเป็นข้อมูลตัวอย่าง (บวกการเปิดหน้าจริงในเบราว์เซอร์นี้)
- รูปวัตถุมงคลเป็นภาพประกอบลายเส้น · ชื่อทีมงานเป็นชื่อสมมติ · รุ่นพระและใบรับรองเป็นข้อมูลสมมติ
- นโยบายความเป็นส่วนตัวและเงื่อนไขเป็นฉบับร่าง ต้องให้ผู้รู้ด้านกฎหมายตรวจ
